# Pre-registration: l10n-guard 0.22.0 (gettext spellings)

Marker: l10n-guard 0.22.0 PREREG v1. Written 2026-11-12 before the build job runs; nothing
below has been run yet. Made with AI agents by MV2 of Munim, Inc. Text CC BY 4.0, code
Apache-2.0.

## The change

glibc and Python's `gettext` module look a message catalog up under the user's locale name
(`zh_CN.UTF-8` -> `zh_CN`, `zh`; `pt_BR.UTF-8` -> `pt_BR`, `pt`): an underscore before the
territory and the territory in capitals, compared exactly on a case-sensitive file system.
Meson and gettext's autotools rules install each `LINGUAS` entry under the name written in
`LINGUAS`. So a translation listed as `zh_cn` or `pt-BR` is compiled and installed but, on
Linux, never loaded.

l10n-guard 0.21.1 gets this half right. For an unlisted `po/nb-NO.po` it already advises
renaming to `nb_NO`, but for an unlisted `po/zh_cn.po` it advises "add 'zh_cn' to po/LINGUAS",
which would ship a catalog nobody loads. Version 0.22.0:

1. **`linguas-unlisted` advice:** names the gettext spelling whenever it differs from the file
   name: `zh_cn` -> `zh_CN`, `nb-no` -> `nb_NO`. The `nb-NO` message is unchanged byte for byte.
2. **New warning `linguas-spelling`:** a language listed in `LINGUAS` with a `.po` file whose
   name is not the gettext spelling (`zh_cn`, `pt-BR`). It is skipped when the gettext spelling
   is also listed, for names that are not locales, and for script codes (`sr-Latn`, `zh_Hant`),
   which are left to the separate linguas-script census.

The code is built in a sealed job from the released 0.21.1 on main by exact line replacements
(`guard_job_0220.py`) with new tests (`test_0220.py`).

## Cases seen before this pre-registration

Two `.po` files with a lower-case territory are known, both from the LINGUAS census's dropped
list: `po/zh_cn.po` in DeimosHall/Metamorphosis (commit 813da90) and in adhami3310/Switcheroo
(commit 8f773bb), each 82 of 83 messages translated and not in `LINGUAS`. Neither `LINGUAS`
lists `zh_CN` (both read on 2026-11-12). They are used for R below, so R is a check that the
code does what it says on known cases, not a test of how often the problem occurs.

## Predictions (fixed now)

- **T (tests):** every test module in the repository passes after the change, including
  `test_0220.py`.
- **M1 (glibc):** with locales `zh_CN.UTF-8`, `pt_BR.UTF-8` and `nb_NO.UTF-8` generated by
  `localedef`, and each one-message catalog installed alone under its own name, the `gettext`
  program (glibc) with only `LANG` set reaches none of the catalogs installed as `zh_cn`, `pt-BR`
  or `nb_no` from any of the three locales, and reaches each control (`zh_CN`, `pt_BR`,
  `nb_NO`) from its own locale. NOT TESTABLE if a locale cannot be generated.
- **M2 (Python):** the same for Python 3.12's `gettext.translation(..., fallback=True)`.
- **S (stability):** on the 18 po folders of the 0.21.1 check, at the same commits, 0.21.1
  and 0.22.0 report the same `linguas-unlisted` and `linguas-missing` findings, with identical
  messages except for keys whose territory is in lower case. NOT TESTABLE if fewer than 16
  folders can be read.
- **R (known cases):** for Metamorphosis and Switcheroo, the 0.21.1 `linguas-unlisted` message
  for `zh_cn` says "add 'zh_cn' to po/LINGUAS" and the 0.22.0 message says "rename po/zh_cn.po
  to po/zh_CN.po and add 'zh_CN' to po/LINGUAS".

Not graded, reported as found: every `linguas-spelling` hit on the 20 folders, each to be
hand-checked on the forge before it is called real.

## Decision rule

0.22.0 is released only if T, M1, M2, S and R all hold. If M1 or M2 fails, the README and
messages claim nothing about lookups that the job did not show, and the change is not
released as written. Verdicts are written by the job and published unchanged; anything decided
after the results is labelled post hoc.

## Limits, stated now

- Case-insensitive file systems (macOS by default, Windows) may find a `zh_cn` folder for a
  `zh_CN` user; the claim is about Linux, where Flatpak and distribution packages run.
- A user who sets `LANGUAGE=zh_cn` by hand would reach the catalog; nobody's desktop does that
  by default.
- Only two lower-case cases are known. How often projects list a misspelled language is not
  measured here.
